# Lecture

One giving of a [deck](DECK.md): one lecturer, particular listeners, one occasion. A lecture has a place it has reached, a path it took to get there, and a memory of what has been said and asked so far. Two lectures from the same deck are never the same lecture.

## Invariants

- **A lecture is live.** What's said is made at the moment it's said, from the slide's notes and from everything that has happened in the lecture so far. Nothing is recorded ahead and played back.
- Everyone in a lecture sees the same [slide](SLIDE.md) and hears the same words.
- A lecture remembers itself. Something said or asked earlier is still known later, and no [question](QUESTION.md) is answered as if it were the first.
- **A lecture can leave the main line and always knows the way back.** After a detour it returns to where it left off, or says out loud that it's moving on.
- A listener can always stop the lecturer.
- A lecture can be paused and picked up later, from where it stopped, still knowing what it has covered.
- A lecture keeps its path: which slides were shown, in what order, what was asked and how it was answered.
- A lecture never changes its deck's main line. It can add slides beside it.
- **A lecture that can't go on says so.** If the lecturer can't be reached or can't be heard, the listeners see that. A lecture never just goes quiet.
